# ADR 0009: Use CapyIO as the working name

- Status: Accepted
- Date: 2026-08-23

## Context

HardwarePool bootstrap naming reflected an audio-oriented first experiment. The
v0.3 product needs a concise working identity for a cross-device I/O fabric.

## Decision

Use CapyIO, “Cross-device I/O Capability Fabric”, for active user-visible names,
crate/package names and the `capyio.v1` pre-alpha protocol package. Historical
references and Git history may retain HardwarePool.

## Alternatives

Keep HardwarePool; defer naming; choose a final commercial brand now.

## Consequences

The migration is intentionally breaking before external protocol consumption.
Trademark/domain/company-brand research remains out of scope.
