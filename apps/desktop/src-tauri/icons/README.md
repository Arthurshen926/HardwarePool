# CapyIO bootstrap icon

The icon set in this directory was generated on 2026-08-20 with the built-in
OpenAI image generation tool, then converted with `tauri icon`.

Prompt summary:

> A centered, vector-friendly application mark showing four independent
> hardware capability modules connected around a shared hub, with navy, cyan
> and violet colors, no text or watermark, on a uniform light cool-gray
> background.

`icon.png` is the canonical 512 px bootstrap source retained in this directory.
The remaining PNG, ICO, ICNS, Appx, iOS and Android files are generated platform
variants. This is a temporary pre-alpha brand asset and may be replaced through
a reviewed design task; it must not be presented as a registered trademark.
